# Office Preview

Просмотр офисных файлов внутри Files OpenChamber. Без редактирования и отправки
содержимого во внешние сервисы. Интерфейс наследует тему и типографику хоста.

Композиция: компактная панель имени/формата и масштаба сверху, содержимое занимает
оставшееся пространство. Для Excel внизу вкладки листов, сверху строка выбранной
ячейки и её формулы; для Word и PowerPoint белый документ на нейтральной подложке.
Листы и страницы переключаются без повторного чтения файла. Цветные значки только
различают формат. Никаких декоративных карточек вокруг документа.

Нужные состояния: получение файла, обработка, пустой документ, ошибка формата,
зашифрованный/повреждённый файл, ограничение размера, готовый просмотр. Значения
формул Excel берутся из сохранённого кеша, пересчёт не обещается.

На узкой панели панель инструментов переносится, документ и таблицы прокручиваются.
Масштаб 50–160%, подгонка по ширине. Отдельные стрелки для слайдов. Для Excel
сохраняются стили, форматы и объединённые ячейки; основные диаграммы отображаются
по сохранённым данным OOXML. Широкие таблицы прокручиваются горизонтально.

Критерий: существующий sales.xlsx открывается вместо штатной заглушки, читаются
все три листа и их суммы; DOCX показывает заголовки, таблицу и изображения;
PPTX показывает минимум два слайда. Клик, масштаб и ошибки проверены в приложении.
