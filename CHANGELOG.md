# Changelog

## 0.1.0 (2026-10-27)

- Read-only XLSX/XLSM, DOCX and PPTX previews inside OpenChamber Files.
- Spreadsheet tabs, cached formulas and basic charts.
- Word pages, tables and embedded images.
- PowerPoint slide thumbnails, navigation and zoom.
- Local rendering without network access or extension capabilities.

[GitHub release](https://github.com/d0kur0/openchamber-office-preview/releases/tag/v0.1.0).
