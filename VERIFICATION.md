# Проверка Office Preview 0.1.0

27.10.2026, Windows x64, OpenChamber Desktop/server 2.5.2, SDK 2.5.2.
Локальная установка папки через `POST /api/guests`, `enabled: true`,
`requested: []`, `granted: []`. Исходники OpenChamber не изменены.

`npm run build` и `npm test`: успешно, 3 теста. Проверены отсечение слишком
большого ZIP до распаковки, запрет внешних путей диаграмм, значение формулы без
кэша и с нулевым кэшем. Это не проверка произвольных повреждённых архивов.

Реальный просмотр в Files интерфейса на `127.0.0.1:3467`, синтетические файлы
из `Documents/OpenCode-Playground/output/demo`:

- `sales.xlsx`: 3 листа, сводка и график; выбор C10 показывает `=SUM(C4:C9)`,
  сохранённое значение 2 616 000 ₽. Значения и источник не пересчитываются.
- `office-demo.docx`: 2 страницы, русский/английский текст, таблица,
  встроенный PNG; на снимке проверена первая страница, обе присутствуют в DOM.
- `office-demo.pptx`: 2 слайда, SVG-график, миниатюры; Next переключает на
  второй слайд и отключается. Проверены широкая и узкая области Files.
- Повреждённый `office-invalid.docx`: понятная ошибка, затем нормальный DOCX
  снова открывается. Временный повреждённый файл удалён после проверки.
- Отдельная панель Office: стартовый экран с кнопкой открытия. Системный
  выбор файла и drag-and-drop отдельно не проверялись.

В процессе исправлены нулевая ширина главного SVG слайда и вызов
`applyHostReady(ctx, document.documentElement)`. После загрузки исправленной
сборки новых ошибок этих типов в консоли не обнаружено.

Снимки находятся локально в
`E:/local-dev/.workspace/tasks/opencode-office-20261027/evidence/`.
Ручное редактирование, пересчёт формул, Microsoft Office и сложные документы
не проверялись. Это локальный прототип просмотра, не редактор Office.

## UI и масштаб, 2026-10-28

Проверены собранный browser bundle и установленная локальная копия в OpenChamber.
В отдельном SDK host fixture просмотрены реальные синтетические sales-report.xlsx,
sales-report.docx, sales-deck.pptx: dark/light, смена темы без повторного открытия,
панели 1000 и 380 CSS px, Excel auto160, ручной400 (increase disabled), PPT Next.
В живом OpenChamber проверены host tokens и новое пустое состояние.
Цвета документов не перекрашиваются. Тесты zoom отдельно проверяют очень широкий
лист/узкую панель, читаемые минимумы страниц/слайдов и буквальный fit.
Это проверка локальных примеров, не полная совместимость со всеми Office-файлами.
